# Sistema Visual — Portfolio

## Cores
| Token | Valor | Uso |
|---|---|---|
| Acento principal | `#F59E0B` | Laranja/âmbar — CTAs, destaques |
| Background base | Tema escuro | Body, cards |
| Texto principal | Claro (tema escuro) | |

> Usar variáveis CSS do `:root` — não hardcodar hex diretamente.

---

## Tipografia
| Fonte | Papel |
|---|---|
| Plus Jakarta Sans | Principal |
| Inter | Corpo/suporte |
| Poppins | Títulos/destaques |

---

## Ícones
- **Material Icons** (Google) — via CDN
- **Font Awesome** — via CDN

---

## Layout
- Sidebar fixa + área principal com seções trocando via JS (SPA-like)
- Responsivo: sidebar adapta para mobile (hamburger/overlay)
- Carrossel de projetos com swipe/drag (mobile) e botões (desktop)

---

## Animações
- Loading screen na entrada
- Scroll reveal em seções
- Hover effects em cards e botões
- `prefers-reduced-motion` respeitado (acessibilidade)
